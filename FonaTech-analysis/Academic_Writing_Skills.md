# Academic_Writing_Skills

## 项目作用

面向论文、综述、学位论文、申请书和审稿回复的可复用技能包。它把学术任务拆成问题范围、材料审查、文献证据、写作、图表、构建和同行式审查等流程。

## 技术与结构

- 以 Markdown/JSON 内容块、配置和 Python 构建脚本组织文档工程。
- `skills/` 提供写作编排、文献证据、语言风格、图表设计、稿件构建和审查技能。
- `tools/` 与 `validation/` 提供安装、校验、哈希和测试支持，并为 Codex、Claude Code、OpenCode 提供适配目录。

## 使用边界

它是流程与内容质量控制工具，不会自动替代真实实验、数据分析或作者验收；项目文档也明确要求对来源、页码、图表和最终渲染结果进行人工复核。
